User Guide

Course Composer

Course Composer assembles multiple pieces of learning content into one ordered, previewable Learning Experience Engine course. Use it for the course-level structure; use Component Studio when you need to build a reusable interaction.

Workflow

Build a course in three passes

1

Course basics

Set the title, description, audience, and learning objectives.

2

Build structure

Add text, images, video, resources, and reusable components. Reorder them in the left outline.

3

Preview + export

Walk through the learner sequence, then export course JSON or a complete project ZIP.

Step 1

Course basics

The course title and description are learner-facing. Audience is stored as structured metadata. Learning objectives appear in the learner preview and travel with the course JSON.

Autosave: Composer stores the current draft in your browser automatically. Project ZIP export is still the portable backup you should keep for important work.
Step 2

Course structure

The left outline is the learner sequence. Select an item to edit it. Drag items to reorder them, or use the arrow controls. Duplicate creates an independent copy; delete removes the item from the course.

Content blocks

Content types

Text

Headings and instructional copy for introductions, explanations, summaries, and transitions.

Image

Supporting text plus an image path and accessible alt text.

Video

Supporting text, video path, optional caption path, and transcript.

Resource

A PDF or other supporting document presented as a learner resource.

Component

An engine-native interaction imported from Component Studio JSON.

Interactions

Using Component Studio with Composer

Add a Component section, then choose Import component JSON. Composer embeds that component definition into the course. Component asset paths can point to the same shared course Project Assets library.

Component Studio
  ↓ Export JSON
Course Composer
  ↓ Add Component → Import component JSON
Course JSON
  └── embedded component definition

This is the first handoff. A later version will support sending a component directly from Studio into the currently open course.

Shared files

Project Assets

Project Assets belong to the whole course. Select a project folder or individual files, then click Use beside an asset to fill the currently selected path field.

my-course/
├── context/
│   └── source-content.txt
├── assets/
│   ├── images/
│   ├── video/
│   ├── audio/
│   ├── captions/
│   └── documents/
└── course.json

Composer stores portable paths such as assets/video/demo.mp4, never an absolute Mac path.

Step 3

Learner preview

The right pane previews the course in learner order. Selecting an outline section jumps to it. Previous and Next move through the sequence. Imported carousel, hotspot, assessment, and media components receive a lightweight Composer preview.

Safety

Autosave, undo, and redo

Composer autosaves the current course structure to browser local storage. Undo and redo track course-content edits during the session. Local asset files cannot be stored permanently by the browser; reopen the project folder or use an exported Project ZIP when resuming work later.

Confidential work

Privacy

Course Composer is a static browser application. Files you explicitly choose are read locally for preview and packaging; choosing them does not commit them to the public GitHub repository. Keep confidential course folders in the private local workspace.
