User Guide

Course Composer

Course Composer assembles a complete learning experience in one authoring canvas. Course-level details, project assets, every content section, learner preview, and export each have a clear place in the workflow.

Workflow

Build a course in five clear steps

1

Course basics

Set title, description, audience, and learning objectives.

2

Upload project assets

Load source context and media before authoring so compatible fields can be filled automatically.

3

Build course content

Add and edit every course section in one visible canvas. Reorder, duplicate, or delete cards directly.

4

Preview

Start from the beginning, move through the learner sequence, or open the full-screen preview.

5

Export

Export course JSON, a complete project ZIP, or inspect the generated engine data.

Step 1

Course basics

The title and description are learner-facing. Audience is stored as structured metadata. Learning objectives appear in the preview and travel with the course JSON.

Autosave: Composer stores the current course structure in your browser automatically. Export a Project ZIP for a portable backup that also includes your selected files.
Step 2

Project assets come before course content

Choose the project folder before adding media-heavy sections whenever possible. Composer classifies the files and can prefill a compatible unused image, video, caption, PDF, or document as you add a new section.

my-course/
├── context/
│   └── source-content.txt
├── assets/
│   ├── images/
│   ├── video/
│   ├── audio/
│   ├── captions/
│   └── documents/
└── course.json

Paths remain portable, such as assets/video/demo.mp4, rather than storing an absolute Mac path.

Step 3

Edit the whole course in one canvas

Every section is displayed as an editable card. You no longer select a section in one pane and edit it in another. Use the controls on each card to move it up or down, duplicate it, delete it, or drag it to a new position.

Text

Introductions, explanations, summaries, and transitions.

Image

Supporting text, image path, and accessible alt text.

Video

Supporting text, video path, caption path, and transcript.

Resource

A PDF or supporting document with a learner-facing button label.

Component

An engine-native interaction imported from Component Studio JSON.

Interactions

Using Component Studio with Composer

Add a Component card, then choose Import component JSON. Composer embeds that component into the course. Its asset paths can reference the same shared Project Assets library.

Step 4

Preview intentionally

Preview from beginning resets the learner sequence to the first section. Previous and Next move through the course. Open full preview expands the learner view so you can review the experience without the authoring controls around it.

Safety

Autosave, undo, and redo

Composer autosaves course structure to browser local storage and keeps an undo/redo history during the session. Browsers cannot permanently retain local file access, so reopen the asset folder or use an exported Project ZIP when continuing later.

Confidential work

Privacy

Course Composer is a static browser application. Files you explicitly choose are read locally for preview and packaging; selecting them does not commit them to the public GitHub repository. Keep confidential project folders in the private local workspace.
