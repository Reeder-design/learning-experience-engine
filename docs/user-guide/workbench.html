User Guide · v0.2

Start with the source, not the structure.

The Workbench is the primary workspace for turning source material, a reusable project pattern, or an existing learning project into an editable experience with a learner preview. Branching scenarios are the first supported project type, and private local mode adds password-protected AI generation and transformation.

Source files

What happens to uploaded files?

Files stay local to the current browser session until you explicitly run an AI action. Text-like reference files (TXT, Markdown, CSV, JSON) can be read in the workspace. Images become selectable in decision/outcome fields and can appear in the learner preview.

Explicit send only. Selecting a source file does not send it anywhere by itself. In password-protected local mode, Generate or Apply AI changes can send the selected reference material to the configured OpenAI API project for that request.
AI transformation

Generate first, then fine-tune

Private local mode supports the actions that matter most:

  • source materials → fully populated scenario project
  • sanitize confidential/internal content for portfolio-safe reuse
  • adapt the project for another audience
  • use the current project as a structural template for new content
  • freeform plain-language project transformations

The local backend calls the OpenAI Responses API, requests strict structured project output, validates branch references and reachable outcomes, and only then loads the replacement project. The previous project can be restored with Undo AI change.

Private local mode

Password protection and local secrets

Run npm run workbench from the repository. The server binds only to 127.0.0.1. On first launch, the browser asks you to create a Workbench password and optionally add the separate OpenAI API key.

  • the password is stored only as a salted PBKDF2-SHA256 hash
  • the API key and password hash live in Git-ignored .env.workbench
  • the login uses an HttpOnly, SameSite=Strict session cookie
  • modifying API requests require a CSRF token
  • sessions expire after about 8 hours
  • Private settings lets you rotate the API key, switch AI models, or change the password later
Public GitHub Pages is not the private manager. The public Workbench remains a safe demo/manual editor; private AI and confidential source workflows are intentionally local-only.
Current boundary

What v0.2 does not pretend to do

Source-template saving is not yet persistent, source files do not survive a browser reload, saved themes are not yet implemented, and only branching scenarios are reconstructed/generated in the Workbench today. The specialized Scenario Builder, Interaction Builder, and Course Builder remain available for fine-tuning while the Workbench expands.
