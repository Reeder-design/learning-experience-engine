Start with the source, not the structure.

The Workbench is the primary workspace for turning a reusable project pattern or existing learning project into an editable experience with a learner preview. Branching scenarios are the first supported project type.

Starting points

Three ways into a project

Start from a template

Begin with one decision point and one outcome when you do not need a template structure.

Open existing JSON

Choose an existing Engine branching-scenario JSON file. The Workbench reconstructs editable fields and a preview from the same structured project.

Source files

What happens to uploaded files?

In v0.1, files stay local to the current browser session. Text-like reference files (TXT, Markdown, CSV, JSON) can be read in the workspace. Images become selectable in decision/outcome fields and can appear in the learner preview.

AI is not connected yet. Selecting a PDF, PowerPoint, Word document, or other source file does not send it anywhere. The next secure API phase will define exactly what source content is sent for AI processing.
AI transformation

What the next phase will unlock

The Workbench is already shaped around the actions that matter most:

  • source materials → fully populated scenario project
  • sanitize confidential/internal content for portfolio-safe reuse
  • apply a saved theme without changing learning structure
  • adapt the project for another audience
  • use the current project as a structural template for new content

The browser will call a secure backend/serverless route; the OpenAI API key will never be placed directly in the public GitHub Pages JavaScript.

Current boundary

What v0.1 does not pretend to do

AI generation is not active yet, source-template saving is not yet persistent, source files do not survive a browser reload, and only branching scenarios are reconstructed in the Workbench today. The specialized Scenario Builder, Interaction Builder, and Course Builder remain available for manual fine-tuning while the Workbench expands.
