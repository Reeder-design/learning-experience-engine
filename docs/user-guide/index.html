Component Studio User Guide

Use Component Studio to build reusable learning interactions from normal form fields, local source files, and assets—without hand-writing JSON or constructing the interaction in Storyline first.

Step 1

Choose a component

Carousel

Best for a set of related items learners should browse, compare, or review one group at a time.

Hotspot reveal

Best for maps, diagrams, workflows, equipment, interfaces, or visual exploration.

Assessment

Best for focused questions with answer-level feedback and completion.

Media presentation

Best for guided video/audio sequences, demonstrations, or narrated examples.

Tip: switching component types starts from that type's template. Export your current work first if you want to keep it.

Files + media

Project Assets

Open Project Assets in Component Studio and select a project folder, selected files, or an existing Studio project ZIP. Studio classifies the files and generates portable relative paths.

my-interaction/
├── context/
│   └── source-content.txt
├── assets/
│   ├── images/
│   ├── video/
│   ├── audio/
│   ├── captions/
│   └── documents/
└── component.json

The structure is recommended rather than required. Studio can classify many files by extension even when they are selected individually.

Interaction content

Component-specific fields

Carousel

Set items per page, then add item titles, body text, image paths, and useful alt text.

Hotspot reveal

Select a background image and position each hotspot using X/Y percentages from 0–100. Add a short label, title, and reveal content.

Assessment

Add questions and answer options, identify the correct option, and write feedback for each response.

Media presentation

Add video/audio segments, choose the media type, assign the path, and add captions/transcript content. Matching VTT files can be recognized in local preview.

Step 3

Preview and test

The right-hand preview is a learner-facing simulation. Click through the component, test feedback, inspect media, and verify when the status changes from In progress to Complete.

Preview assets are local: when you choose files from your Mac, Studio creates temporary browser URLs so you can test them without uploading those files anywhere.
Behind the interface

Generated JSON

Generated JSON is the engine-native component definition. Component Studio writes and updates it for you. You can inspect or copy it when useful, but normal authoring should happen through the form.

Step 4

Important

Privacy and confidential work

Component Studio is hosted as a static GitHub Pages app, but the local files you explicitly select are read by your browser and are not automatically committed or uploaded to GitHub. Keep confidential project folders in your private local workspace and never place them inside the public engine repository.

Help

Troubleshooting

I do not see the latest interface

GitHub Pages may still be deploying, or Safari may be showing cached files. Refresh the page; if needed, use a hard refresh.

My asset is not filling a path

Click the path field first, then choose Use beside the asset. You can also use Auto-fill paths for compatible empty/default fields.

My media does not preview

Confirm the media file is included in the current Project Assets session and that the path shown in the field matches the Asset Library path.
