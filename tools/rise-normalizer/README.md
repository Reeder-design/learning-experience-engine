# Rise Normalizer

Converts an extracted Rise course project into the Learning Experience Engine draft normalized schema.

## Why this exists

The Rise Extractor preserves Rise-specific structure faithfully. The Rise Normalizer creates a cleaner authoring-tool-neutral layer that the engine can eventually render to multiple targets.

The normalized format is still **draft and Rise-informed** until Storyline web output has also been inspected.

## Input

A folder generated by `tools/rise-extractor` containing at least:

- `course.json`
- `assets.json`
- `source-manifest.json`
- `lessons/`
- `assessments/`

## Usage

```bash
npm run normalize-rise -- ../learning-content-private/exports/pcn-rise-extracted
```

By default this writes to:

```text
<extracted-course-folder>/normalized/
```

You may choose another output folder:

```bash
npm run normalize-rise -- ../learning-content-private/exports/pcn-rise-extracted --output ../learning-content-private/exports/pcn-normalized
```

## Output

```text
normalized/
├── course.json
├── assets.json
├── normalization-manifest.json
├── lessons/
└── assessments/
```

## Data-safety rule

Normalized files generated from confidential source courses are still confidential. Keep them in `learning-content-private` or another approved private workspace. Do not copy real internal course output into this public repository.

## Loss prevention

Normalization intentionally preserves original source data under `source.raw` for blocks and questions. The original lossless Rise data also remains available in the extractor output under `_source/`.
